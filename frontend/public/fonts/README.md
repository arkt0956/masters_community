# 웹폰트 배치

`DR-P08`이 요구하는 두 파일을 이 디렉터리에 둔다. 저작권 파일이라 저장소에 담지 않았다.

| 파일명 | 서체 | 라이선스 |
| --- | --- | --- |
| `nanum-daughter-mom.woff2` | 나눔손글씨 딸에게 엄마가 | SIL Open Font License |
| `noto-sans-kr.woff2` | Noto Sans KR | SIL Open Font License |

두 파일이 없어도 화면은 뜬다. `font-display: swap`이라 대체 서체로 그려질 뿐이다.

## 주의

- **서브셋을 만들지 않는다.** 사용 글자만 남기면 파일 크기가 크게 줄지만 폰트 수정에
  해당할 수 있어 OFL의 예약 폰트 이름 조항 확인이 필요하다. 확인 전에는 원본을 그대로 제공한다 (`DR-P08`).
- **글꼴 고지는 필수다.** 웹폰트로 제공하면 파일이 이용자 브라우저로 전달되므로 배포에 해당한다.
  서비스 정보 페이지(SCR-008)에 OFL 고지가 들어 있다 (`DR-X01`).
- 내려받은 파일에 Bold가 실제로 있는지 먼저 확인한다. 나눔손글씨 계열은 단일 굵기로 배포된다.
